# Prerequisites

Part of [[Simulator]]

Everything you need installed before you [[Launching and configuration of the simulator|launch the simulator]].

## Repo
- Clone the robot repository you want to simulate. I'll be using the 2026-Rebuilt repo in these examples since it is the most up-to-date one.

## Software
- Your IDE, installed and configured (see [[Installing your IDE]] for help)
- AdvantageScope (the WPILib installer already bundles a copy, so this standalone download is optional): https://github.com/Mechanical-Advantage/AdvantageScope/releases/latest
- Elastic (also bundled with the WPILib installer, standalone download optional): https://github.com/Gold872/elastic_dashboard/releases/latest
