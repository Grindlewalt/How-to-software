# How to Software on the 4911 Cyberknights
So, you are here to learn how to do Software on the 4911 cyberknights. This guide will be just on how to install obsidian and open this up.
## Getting Obsidian:
Download and install Obsidian here: https://obsidian.md/download
## Opening these docs:
Either clone this repo: https://github.com/Grindlewalt/How-to-software.git
or js download the .zip from the green code button > download .zip
Open obsidian and set the file to be your vault
click the 'How to software on the 4911 Cyberknights.md'
Navigate from there to each tutorial and section you want to go over.
